# 🚗 Lista de Coches Pendientes de Subir a Instagram

Aplicación web personal para organizar avistamientos de coches, preparar publicaciones de Instagram y planificar futuros posts.

## ✨ Funcionalidades

- **Colección de coches:** guarda cada avistamiento con título, fotografía y descripción.
- **Compresión de imágenes:** reduce el tamaño de las fotografías para ahorrar espacio.
- **Publicaciones de Instagram:** guarda el texto preparado para acompañar cada publicación.
- **Lista de próximos posts:** organiza los coches pendientes de publicar y cambia su orden.
- **Calendario editorial:** asigna coches a fechas concretas para planificar las publicaciones.
- **Copias de seguridad:** exporta e importa los datos mediante archivos JSON.
- **Almacenamiento local:** los datos se guardan en el dispositivo y navegador utilizados.

## 🛠️ Tecnologías

- HTML
- CSS
- JavaScript
- IndexedDB para el almacenamiento local
- Vercel para el despliegue
- GitHub para el control de versiones

## 📱 Aplicación web progresiva (PWA)

El proyecto se está preparando para poder instalarse en dispositivos compatibles como una aplicación, con nombre e icono propios.

La versión inicial no incluye funcionamiento sin conexión ni sincronización automática entre dispositivos.

## 💾 Datos y copias de seguridad

Los coches, las fotografías almacenadas y la información de planificación pertenecen al almacenamiento local de cada dispositivo y navegador.

**Importante:** abrir la aplicación desde otro dispositivo no transfiere automáticamente los datos. Exporta copias de seguridad JSON periódicamente para evitar perder tu colección.

## 🚀 Despliegue

La aplicación está publicada en Vercel y vinculada a este repositorio de GitHub. Los cambios confirmados en la rama configurada pueden desplegarse automáticamente.

## 🔒 Privacidad

La colección se almacena localmente en el navegador. La URL de la aplicación puede ser pública aunque el repositorio de GitHub sea privado.

No introduzcas información sensible y protege el acceso a los dispositivos donde utilices la aplicación.
